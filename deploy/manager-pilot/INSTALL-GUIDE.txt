AI VISUAL BUILDER (PILOT) - INSTALLATION GUIDE
==============================================
Version 10.18 for Windows 10/11 (64-bit) with Microsoft 365 PowerPoint desktop. About 5 minutes.
The package is the full desktop version: one-click Generate with Claude and Napkin, the large gallery and hover
previews, insert as editable shapes, Several slides, Edit a visual, Undo, and the Simplilearn template check.
It contains its own Python runtime, so there is nothing else to install. No administrator rights are needed.

BEFORE YOU START
- The organization's Napkin AI API token and Anthropic (Claude) API key, from whoever manages them. They are typed
  in once during installation (hidden) and stored only for your Windows user. They are not in this package.
- Close PowerPoint (save your work first).

INSTALL
1. Copy AI-Visual-Builder-Pilot-10.18.zip to your PC (e.g. Downloads).
2. Right-click the zip > Extract All > Extract.
3. Open the extracted folder "AIVB Pilot" and double-click "Install AI Visual Builder.bat".
   - If Windows SmartScreen says "Windows protected your PC": More info > Run anyway (only for this file).
4. When Windows asks whether to install a certificate for "localhost", choose YES.
   (It lets PowerPoint load the add-in from your own PC over HTTPS. Uninstall removes it.)
5. Paste the Napkin token, press Enter; paste the Claude key, press Enter. Nothing is shown while you paste.
6. Wait for "AI Visual Builder 10.18.0 is running", then press any key to close the window.

USE
1. Start PowerPoint and open a deck on the Simplilearn LVC template. Select a Content_Slide.
2. Home tab > AI Visual Builder > Generate visuals. The panel opens on the right.
   If the group is missing after restarting PowerPoint: Home > Add-ins > More Add-ins > MY ADD-INS >
   Upload My Add-in > Browse > %LOCALAPPDATA%\Programs\AIVisualBuilderPilot\manifest-pilot.xml > Upload (once).
3. Paste slide content (or use the text already on the slide) and press Generate visuals.
4. Rest the pointer on a design to see it large; "Open large gallery" shows all of them.
5. Double-click a design to insert it. Click any text on the slide to edit it. "Undo last insert" removes it.
6. "Several slides" splits long content over several slides; "Edit a visual" changes an inserted visual.
Napkin and Claude requests are paid by the organization. The panel shows when it uses them; designs it has
already made for the same text are reused at no cost.

CHECKLIST (first use)
[ ] Panel opens (no "Sorry, we can't load the add-in")
[ ] Generate gives many designs, including ones marked as designed by Napkin AI or Claude
[ ] Hover preview and large gallery work
[ ] Insert, edit a text on the slide, move a shape
[ ] Undo last insert
[ ] Several slides, Edit a visual

IF SOMETHING GOES WRONG
- "Sorry, we can't load the add-in" or the panel cannot reach the service: double-click
  "Restart AI Visual Builder.bat" (in %LOCALAPPDATA%\Programs\AIVisualBuilderPilot), then reopen the panel.
- No Napkin/Claude designs: double-click "Set AI keys.bat" in the same folder and enter the keys again.
- The installer says the certificate was not trusted: run it again and choose Yes; if the question never
  appears, company policy blocks it - contact IT.
- The .bat closes immediately with a policy error: company policy blocks PowerShell scripts - contact IT.
- Log file: %LOCALAPPDATA%\AIVisualBuilder\server.log

UNINSTALL
Settings > Apps > Installed apps > "AI Visual Builder (Pilot)" > Uninstall, or double-click
"Uninstall AI Visual Builder.bat". It removes the add-in, the background service, the certificate (Windows asks to
confirm: Yes), the stored keys and the program folder. Other add-ins and your presentations are not touched.

WHAT IS INSTALLED (for IT)
- %LOCALAPPDATA%\Programs\AIVisualBuilderPilot   app + Python 3.14.7 (python.org, signed) + anthropic SDK 2.3.0
- %LOCALAPPDATA%\AIVisualBuilder                 localhost certificate, keys (readable only by the user), usage, log
- %ProgramData%\AIVisualBuilder\access.json       who may generate (this Windows account) + template check
- HKCU\Software\Microsoft\Office\16.0\WEF\Developer   PowerPoint add-in registration (sideload, this user only)
- Startup folder shortcut "AIVisualBuilderPilot"   starts the service (pythonw.exe, https://localhost:44317 only)
- Current-user "Localhost" root certificate "AI Visual Builder pilot (localhost)"
Network: outbound HTTPS to api.napkin.ai and api.anthropic.com only. The service listens on 127.0.0.1 only.
